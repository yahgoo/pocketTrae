# PocketTrae

PocketTrae is a cross-device action hub for TRAE that keeps AI workflows moving when human approval is needed. Desktop TRAE prepares the action, mobile receives a structured approval card, and the workflow continues immediately after a tap response.

## What it solves
AI workflows often stall when a human decision is required. PocketTrae reduces that friction by moving approvals to mobile and keeping TRAE as the orchestration hub.

## Demo
- Desktop: `http://localhost:3000/desktop/`
- Mobile fallback: `http://localhost:3000/mobile/`

## Key features
- Cross-device approval flow.
- Mobile action cards.
- Desktop workflow continuation.
- Browser fallback for demo reliability.

## Use cases
- Deploy approvals.
- Incident acknowledgements.
- Human-in-the-loop ops workflows.

## Tech stack
- TRAE SOLO.
- HTML, CSS, JavaScript.
- Node.js / Express.
- Server-Sent Events for live updates.
